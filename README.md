### 📌 Project Overview

This project uses a trained **Artificial Neural Network (ANN)** model to predict energy output based on environmental factors.

The application allows users to:

* Input real-time feature values
* Upload CSV files for batch prediction
* View predictions with simple comparison charts
* Understand results through clean visual insights

---

### 🧠 Key Features

- ✨ Real-time energy prediction  
- ✨ Batch prediction using CSV upload  
- ✨ Clean and modern dark UI  
- ✨ Feature comparison (Bar chart)  
- ✨ Prediction trend visualization  
- ✨ Prediction history tracking  
- ✨ Fully deployable (Streamlit Cloud)
